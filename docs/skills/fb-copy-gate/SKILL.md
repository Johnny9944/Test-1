# fb-copy-gate

这份 skill 把 wabot 线上「质量闸门 Gate」的规则写成人话,让每个会话写出来的文案第一次就能过闸。改 Gate 本身时,同步改这里。

## 硬规则(不满足就不要交付)

1. **首句点名产品。** 第一句的前 6 个字内出现产品名:D'Nitez(睡眠线)、Gesund Pro(眼护线)、FlexGuard(关节线)、Ruume 鹿肽素(鹿肽素线)。读者一眼知道你在卖什么。
2. **分段。** 每段最多 3 行,段与段之间空一行;不用 markdown 符号(`**`、`#`、`-`),Facebook 不渲染;不在段落中间硬换行,WhatsApp 会原样显示断行。
3. **不宣称疗效。** 马来西亚 Medicines (Advertisement and Sale) Act 1956(Act 290)与 KKM 规定:不得宣称治疗、治愈、预防法定疾病清单上的病(清单放 `references/act290-diseases.md`,由 CC-A 从官方来源核对后补齐,补齐前一律不写任何病名)。不写「治好」「根治」「预防糖尿病」「降血压」「100%」「保证」「无副作用」「医生推荐」「临床证明」;不用前后对比图和名人见证当疗效证据。可以写:成分、用法、感受描述(「睡前一杯,早上起来精神」)、生活场景。
4. **HALAL。** 只有持证产品才写 HALAL,并按 HANDOFF 里的证书号写法;不写「清真认证中」。
5. **帖尾结构固定。** 倒数第二段是行动号召(一句),最后一段是来源码 + wa.me 链接:`https://wa.me/60167650225?text=` 后面整段用 `encodeURIComponent` 编码(空格是 `%20`,`#` 是 `%23`),预填文本必须含该帖的来源码(#FB_DNG / #FB_GSD / #FB_FLX / #FB_RUM;多平台上线后改用每帖唯一码)。链接前后不要加标点。
6. **语言。** 按目标客群写:华人客群用简体中文,马来客群用马来文,年轻客群可用 Manglish;不在一句里混三种语言;不用只有中国大陆才用的词(「宝子」「家人们」)。
7. **去 AI 腔(中文)。** 不用「不是…而是…」、三连排比、「值得注意的是」「总而言之」「让我们」;不用破折号;不用金句收尾;不用感叹号连发;每段只讲一件事;数字写阿拉伯数字。
8. **长度。** FB 120–220 字;IG 80–150 字(正文链接不可点,来源码放正文、链接放简介);Threads ≤ 500 字符;WhatsApp 单条 ≤ 3 段。

## 交付前自检(逐条打勾再交)

- [ ] 首句前 6 字有产品名
- [ ] 无 markdown 符号、无硬换行、段间空行
- [ ] 无疗效宣称、无病名、无「保证 / 100% / 无副作用 / 医生推荐」
- [ ] HALAL 写法正确或不写
- [ ] 帖尾:行动号召 → 来源码 + 已编码的 wa.me 链接;解码后能看到来源码
- [ ] 语言单一、无 AI 腔词、长度在范围内
