# PLAN-ads-engine v1.1 — 广告引擎(SE-10…SE-24)

高客单一对一成交:广告不是买便宜线索,是每周把 10–20 个买得起、主动问价的人送进 WhatsApp。北极星是 CPQL 与 Sales:Ads。

## 0. 三道出场硬闸(不过则一分钱不花)
1. **公司书面许可**:写明可投付费广告、可用哪些素材、责任归属。
2. **KKLIU**:马来西亚面向公众的注册保健品广告须先经药品广告局批准(网络/社媒类约 30 天),批文只能由 **MAL 持证公司**申请,分销商申请不了。必须书面二选一:(a) 公司给已批 KKLIU 素材;(b) 公司书面承担「不提功效版」广告的合规责任。在此之前只做自然帖。
3. **接单产能**:老板每天能不能回 5–8 个线索?不能就不许升到 RM250/天。

## 1. 指标
口径先修:2025-10 Enquiry=1 却 Closed=2,两列不是同一批人;历史 25.9:1 含老客回购,**不是广告 ROAS**,别再对外引用。
- Sales:Ads 滚动30天 ≥4:1;<2:1 冻结扩量,<1:1 全停
- 允许 CAC = 客单÷4 = RM600–760
- 对话→成交 约4% → 目标6–8%(真杠杆,不是加预算)
- 常驻 8 条当日有花费的 ACTIVE ad

## 2. 漏斗(全为占位,A-1 后用实测替换)
F1 曝光→F2 点击→F3 进线(带 #AD_ 码)→F4 合格线索(≥2 轮且问价/用法/成分)→F5 成交。
RM250/天约:展示 8k–20k、点击 120–250、**进线 4–10(点击→进线 3–6%,原方案 25–40% 与 CPL RM25–60 自相矛盾)**、QL 2–5、成交 0.2–0.4/天 ≈ 6–12 单/月 ≈ RM18k–37k。**4:1 是要努力才够得到的线。**

## 3. 创意
角度池:场景痛点(写时刻不写病)/人群定点(职业与人生阶段,禁身体状态点名)/成分工艺/价值锚定/计数型社会证明/老板第一人称(30%,最易过闸)。钩子:数字、时间、真实问句、**拒绝钩**(「只想找便宜的,这个不适合你」)。资格前置是内核:宁可 CPL RM30→RM55 换成交率翻倍。
文案 5 段:钩子→场景/证据→产品与做法→资格句→CTA+预填。去 AI 腔:禁「解锁/赋能/打造」「不是…而是…」、禁三连排比与金句收尾;钩子须含一个编不出来的细节。
**产量对齐槽位**:常驻只有 8 条,所以**每周全线只上 2–3 条新 ad**(单变量:新钩子×胜出角度),永远留 1 条冠军当基准,已批库存 ≥4。换序:钩子(7–10天)→主图(14–21天)→角度→受众。
素材:公司审批素材 > 老板实拍 > AI 场景图。AI 图只做静物/环境,不生成真人、包装、前后对比,须标「图片由 AI 生成」。**实拍是老板的真金时间:每线每月 5 张 + 2 段短片≈2 小时,先只做 1 线。**
三槽位预填(≤30字、码放最后、无健康词):「给我自己 #AD_DNG_0915A」/「给家人 …B」/「怎么卖?…C」,wabot 按后缀走三套开场白。

## 4. 结构与预算
两把独立系统用户 token 只隔离**凭证**爆炸半径;**政策处罚落在 Page 与 Business 层,广告违规一定连坐同一 Page 的自然流量**,这条消不掉,只能内容保守 + 前 4 周只投 1 线 + 每线预备一个备用 Page。
每线 1 个常青 campaign、1 个 adset(ABO 不用 CBO)、挂 3–4 条 ad。**诚实说明:RM250/天摊到 4 线,每 adset RM60/天,按 CPL RM50 每周约 8 个事件,远低于学习期 50/周,四线会长期 Learning Limited。**对策:A-1/A-2 只投 1–2 线、单线堆到 ≥RM80/天;四线齐投等预算 ≥RM400/天,否则认下效率折扣并写进复盘。
受众:全马、25–65、广泛+Advantage(排除 Audience Network);不做健康状况定向,不投招代理。命名 `AD_<LINE>_<MMDD><X>_<HOOK>_<ANGLE>`,后缀与来源码逐字相同。阶梯 RM40→80→150→250,每档须过退出标准。

| 规则(SE-15 每日08:00) | 条件 | 动作 |
|---|---|---|
| R1 早杀 | 花 ≥3×实测CPL(暂 RM150)且 0 进线 | PAUSE |
| R2 慢杀 | 花 ≥RM300 且 CPQL >2×目标 | PAUSE |
| R3 观察窗 | 花 <RM150 或上线 <5 天 | 一律 KEEP |
| R4 扩量 | CPQL ≤目标连3天且 freq<2.0 | 提议 +20%,老板按钮 |
| R5 冷却 | 改预算后 72 小时 | 不得再改 |
| R6 疲劳 | freq ≥2.5 或 CPL 周环比 +40% | 换创意 |
| R7 退休 | 单 ad 连跑 21 天 | 下架 |
| R8 冠军保护 | CPQL 最低那条 | 不自动 PAUSE,**除非合规 block、freq≥4 或账户红线** |
| R9 补位 | 活跃 ad <8 | 从已批库存补(不加预算,故可自动)+告警 |
| R10 产能 | 昨日线索 24h 未回 >3 个 | 冻结扩量并降一档 |

**R1 从 RM60 提到 RM150 的原因**:CPL RM50 时 RM60 只够 1.2 个线索的期望,零进线约三成纯属运气,原阈值会误杀好广告。
**单位铁律**:Marketing API 预算字段用**账户货币最小单位(sen)传字符串**,RM250/天 = `"25000"`;写入后必须 GET 回读断言,并加原生规则「账户当日花费 >RM400 自动 PAUSE」(不是只通知)。写错一位就是 100 倍。
自动暂停须 ≥1,000 展示或 ≥RM50 花费。加预算/开新 adset/换受众一律老板按钮。

## 5. 工作流(前缀 SE、KL 时区、Header Auth、上线老板点 Publish、n8n 升 2.38.x 后再建)
SE-10 创意工厂(周日出 8–10 概念,不是 24)· SE-11 素材配装 4:5/9:16 · SE-12 Gate-Ad · SE-13 审批包(**逐条点批,取消一键全批**;未回则只上库存)· SE-14 建广告一律 PAUSED + 回读断言 · SE-14b 上线 · SE-15 优化器 R1–R10 + decision_log · SE-16 Insights(字段读 ad_metric_map)· SE-17 归因合流 · SE-17b 原生兜底(日花超标自动 PAUSE)· SE-18 写回 `AUTO_daily` · SE-19 哨兵(拒登/受限/**ACTIVE 但 0 花费**/spend_cap 到 80%/活跃 ad<8)· SE-20 记分卡 · SE-21 评论守卫 · SE-22 合规闸(许可或批文为空即拒建)· SE-23 台账(**留存 7 年**)· SE-24 `/adstop`。
**n8n 挂了的急停**:老板手机 Ads Manager 把账户支出上限改成当前已花额 —— 唯一不依赖系统的刹车,写进 SOP。

## 6. 合规
广告全进 Meta 广告资料库,谁都能搜;付款卡直通老板本人。**广告 100% 人审、逐条批,永不自动放行。**
- L0 法律(硬 block):Act 290 附表病名;三语疗效词(治疗/治愈/根治/预防·cure/treat/heal·ubat/sembuh/merawat);无 KKLIU 时**一切功效与健康收益句**;名人与专业背书;前后对比;100%/保证/无副作用/医生推荐。
- L1 Meta(block):第二人称健康状况暗示(「你是不是也睡不好」)是拒登头号原因,一律改第一/第三人称;虚假稀缺;未标 AI 图。
- L2 风控(warn→人审):品牌名是否在许可 scope 内;价格与收入机会;竞品比较;simhash 去重。
平台放宽≠本地合法。预填首句与 wabot 开场白同样过 Gate;评论回复等同广告内容。只存 wa_hash,不把客户原话自动抓进创意,PDPA 未明前不上传名单。同一 Page 30 天内 3 次拒登 → 全线停投 7 天。

## 7. 归因与写回
四重:①来源码(主链,A/B 双轨都带)②命名 ad_id↔source_code ③ctwa_clid(仅 Cloud API)④时间邻近(**仅参考,不参与关停**)。
**关停前先补口径**:无码线索按当日各 ad 花费占比分摊后再算 CPQL,否则 30% 无码率会系统性高估 CPQL、误杀好广告。无码率 >30% 连续一周 → 改文案不改系统。
并列 `ratio_attributed`(真 ROAS)与 `ratio_all`(老板现用),并列现金口径 vs 队列口径(成交归首次进线月);成交滞后 3–21 天,终判用滚动 30 天。写回只新建 `AUTO_daily`/`AUTO_monthly` 分页,主表 6 列一格不动;Enquiry 按去重 wa_hash 产出;A Client 定义确认前不写;每月 1 号三方对账。

## 8. 阶段(时钟从公司书面回复那天起算)
- **A-0 地基 W1–2**:SE-22/23、Gate-Ad、9 张新表、SE-16/17 只读、原生规则、口径修订。老板:拿回书面许可(硬阻塞)、建 ads token、spend_cap RM1,500、定义 Enquiry/A Client。出场:清空许可后 SE-14 拒建;能 GET /act_X。
- **A-1 买数据 W3–5,预算 RM1,600(单线 RM80/天×20天)**:原方案 RM560 只买得到约 11 个线索,统计上证明不了任何事。这一档的产出是**真 CPL、真合格率、归因通不通**,不是 ROAS。出场:≥30 进线、无码率<30%、A/B 双轨跑通。
- **A-2 闭环 W6–7**:SE-15/18/19/24 上线,自动 PAUSE 放开,`/adstop` 演练。出场:连续 7 天全自动、对账 ±RM5、滚动 ≥3:1。
- **A-3 扩线 W8–11**:按单线表现逐条加,不四线同开;四线齐投等预算 ≥RM400/天。出场:滚动30天 ≥4:1,或说得清是哪一层掉的。
- **A-4 稳态**:KKLIU B 轨、再营销 PDPA 评估、月度对账签字。

## 9. 成本与老板时间
系统 RM15–35/月;实拍外包 RM300–800/次;KKLIU 由公司走。
**老板真实时间(10 分钟/周是低估)**:A-1/A-2 每周 60–90 分钟(审创意 20、上线 5、看日报 15);稳态每周约 30 分钟 + 每月 2–3 小时拍素材 + 对账 30 分钟。**回 WhatsApp 的时间不算在内,那才是大头。**

## 10. 未核实(别当事实讲)
① wabot 是否走 Cloud API(决定 ctwa_clid);② CTWA 的 `page_welcome_message` / `autofill_message` 能否稳定带 `#AD_` 码、用户会不会删掉;③ Marketing API Development Access 对自有账户的额度上限(升 Standard 需 15 天内 500 次调用、错误率<15% 且过审);④ MYR 最小日预算与 spend_cap 触顶后的行为;⑤ 消息类 action type 是否弃用;⑥ adrules_library 的 schedule_spec、能否读到拒登原因;⑦ KKLIU 是否每个变体各需批文、「完全不提功效」是否真豁免(**建议花钱问一次大马律师或公司合规,这是最贵的未知**);⑧ PDPA 2024 下哈希名单上传是否需同意;⑨ 所有区间数字均为占位。
