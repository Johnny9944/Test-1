# 三个副业与「AI 公司架构」的判断(2026-09-15,规则已联网核实)

> 老板:YouTube 做胎教/儿歌频道、TikTok 做 AI 剧、小红书卖 Ruume;「用更少的心思和时间赚更多的钱」;要不要设总裁/总监/产品经理/运营/市调等子 AI;怎么最快、最稳看到成果。本文是主控的判断,数字来源见 §5。

## 0. 一句话
- 不设总裁/总监子 AI。有证据的做法是「一条主线程决策 + 2–4 个各管一个可核实交付物的执行 agent + 只看证据的验证 + 碰钱/身份/发布留给人」,这就是我们现在的结构。
- 三个副业只有小红书卖 Ruume 能接到现有的赚钱机器上,做;TikTok 的 AI 视频技能改成给主线做内容;YouTube 儿歌是三个里最差的赌注,要做也只做 60 天小试并设停损。
- 最快最稳:先把主线闭环上线(本周),再加第二流量口(小红书),再让一条视频喂四个平台,11 月开投。每个业务一个数字、一个停损。

## 1. 结构题:为什么不搭「AI 公司科层」
| 证据 | 数字 | 含义 |
|---|---|---|
| 受控实验《Towards a Science of Scaling Agent Systems》(arXiv 2512.08296,4 个基准 / 180 组配置) | 无协调多 agent 错误放大 17.2×;有「主管」协调仍 4.4×;单 agent 成功率 >45% 后再加协调层收益转负;收益在约 4 个 agent 处见顶 | 多加管理层不降错,反而放大 |
| CrewAI 官方文档 | 加一层「经理 agent」比顺序管道多耗 30–50% token | 经理层是纯成本 |
| Anthropic 多 agent 研究系统 | 研究类任务提升 90.2%,但 token 约 15 倍;明确说不适合环环相扣的工程任务 | 只在可并行的调研上用多 agent(我们的工作流评审就是这么用的) |
| Devin 团队「Don't build multi-agents」 | 会改状态的「写」操作留在一条线程;其他 agent 只做只读调研 | CC-A 是主线唯一的写手 |
| Berkeley MAST(1,600+ 条轨迹,14 种失败模式) | 失败主因是职责不清与缺验证,不是模型不够聪明 | 要的是清晰交付物 + 验证,不是头衔 |
| Reflexion vs「LLM 不能自我纠错」 | 有测试/执行结果做依据的反思有效;纯自评常无效 | harness 三个数、哈希证明、联网核实,不是自吹 |

我们现在的结构就是这个:主控(计划、核对、每周复盘)→ CC-A(主线唯一写手)/ CC-B(内容与广告)/ CC-C(数据与调研,只读)→ 工作流评审做验证 → 老板只做身份绑定与花钱的动作。要加的不是职位,是三样:每条业务一个指标 + 停损规则;每周一次只读市场扫描(CC-C);每月一次复盘(主控)。

## 2. 三个副业逐个判
| 副业 | 已核实的硬事实 | 判断 | 若要做 |
|---|---|---|---|
| YouTube 胎教/儿歌 | YPP 门槛 1,000 订阅 + 4,000 小时或 1,000 万 Shorts 播放;2027-02-01 起新申请门槛翻倍(8,000 小时 / 2,000 万);儿童内容关闭个性化广告、评论、会员、Super Thanks;儿童 + 音乐 + 东南亚受众三重折扣,RPM 报道多在 USD 0.5–3(普通内容 5–15);2025-07 起「批量模板/非原创」内容不给变现,AI 循环音乐是典型高风险;同类频道极多;变现一般 6–18 个月 | 三个里最差:时间长、单价低、被判「非原创」的风险高。与「少心思多赚钱」相反 | 只做 60 天 10 条试验,每条不同编曲与画面(不循环、不模板);停损:60 天订阅 <1,000 或总观看 <50,000 即停;不占主线资源 |
| TikTok AI 剧 | 马来西亚是否有播放分成(Creator Rewards)各方说法不一,官方确认名单不含马来西亚;可用的是 LIVE 打赏(1,000 粉、18+)、TikTok Shop 带货佣金(无门槛)、品牌合作;AI 生成 60 秒成片约 USD 15–50;AI 内容必须打标;ReelShort/DramaBox 不收散户投稿,走委托与授权;海外短剧市场 2026 约 60 亿美元、AI 短剧子类增长快但入口是平台委托 | 作为「剧」没有稳定收款口;作为「AI 视频能力」很有用 | 不单独开号追剧集。把 AI 视频拿来做主线与 Ruume 的产品内容(轻视频管线已出样片);TikTok 号发同一批内容,带货走 TikTok Shop 联盟若公司允许上架(公告 2025-01-27 电商平台未授权,先问公司) |
| 小红书卖 Ruume | 马来西亚华人渗透高、美妆护肤转化最好、女性 20–35 为主(行业估计);2026-02-10 起小红书全面禁止达人推广保健食品(含图文笔记、评论、私信、主页签名),跨境未认证保健品在灰区,行业建议停硬广;站外导流(WhatsApp)是另一重灾区,阶梯限流到封号;马来西亚 KKLIU 对功效宣称有要求 | 唯一能接到现有 wabot 漏斗的副业,做,但只能走「素人日常保养分享」路线 | 不提功效、不挂链接、不喊 WhatsApp;联系方式只放主页,让用户主动来;一周 3 帖,手机手发 5 分钟;进线走同一个 wabot 与 Ratio 口径;官方素材、零售价、公司规矩不变 |

合同边界:儿歌与 AI 剧不属健康类电商,不触发经销合同 12.1/13.2;小红书卖 Ruume 属公司产品,受官方素材、零售价、不上电商平台等规矩约束。

## 4. 已修正的几处
- YouTube 2025-08 的「年龄估计」是观众端功能,不会替创作者自动打「儿童内容」标;儿童内容判定仍靠创作者自报 + 平台分类器。
- TikTok Series(付费连载)马来西亚是否可用未能核实,本文不作为依据。
- 马来西亚 RM25,000/RM50,000 罚则出自《1952 年药物销售法令》与 1984 条例(针对未注册产品销售),广告宣称归《1956 年药物广告及销售法令》与 KKLIU 审批;两者都要遵守,但别混为一谈。
